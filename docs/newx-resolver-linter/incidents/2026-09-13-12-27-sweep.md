scrolling, and the For You topic request, the normal script reaches Dynamic
color and aborts. A continue-on-error run exposes additional independent
12.27 contract failures.

the old per-entry Compose renderer no longer exists in 12.27.

## Isolation and current repairs

- `:patches:lintNewxResolvers` passes after every source change listed below.
- Custom sharing follows one resolved `goto` before the shared URL builder.
- Drawer resolves the content renderer by semantic parameter shape and ignores
  generated forwarding calls that carry a pre-resolved title.
- Automatic refresh no longer depends on removed Kotlin null-check strings;
  repository and event roles are resolved from timeline types, `AUTO_REFRESH`,
  and the repository request call.
- Pager resolves both the old 18-parameter ABI and new 17-parameter ABI under
  the Google repackaged-holder scope, anchored by the Compose `Vertical` enum.
- For You topic filtering no longer requires the removed `requestType` string;
  its `FOR_YOU` enum read and resolved HomeTimeline constructor remain unique.
- The unresolved failures require separate capability adapters. Do not widen
  all fingerprints globally or silently skip them: the continue run proves
  that the 12.27 release contains both Compose/library churn and unrelated
  product/model refactors.

### Final resolutions and sweep completion

All remaining failures from the diagnostic sweep have been resolved and validated on both `12.26.0-alpha.03` and `12.27.0-alpha.01`:

#### Hide compose button (`HideNewPostButtonPatch.kt`)
- **Cause:** Removed `"onClick"` parameter string and Compose layout refactoring in 12.27.
- **Repair:** Replaced string filter with Compose modifier-to-`AnimatedVisibility` data flow tracing.
- **Artifact:** `docs/newx-resolver-linter/artifacts/hide_compose_button_recon.md`.

#### Hide post dividers (`HidePostDividersPatch.kt`)
- **Cause:** Removed `"$this$threadConnector"` and `"replyFacepileState"` parameter strings.
- **Repair:** Anchored on canvas draw call structure and thread collection traversal.
- **Artifact:** `docs/newx-resolver-linter/artifacts/hide_post_dividers_recon.md`.

#### Hide post reply bar (`HidePostReplyBarPatch.kt`)
- **Cause:** Removed `"inlineComposer"` and `"hazeState"` compiler strings; photoviewer class rename.
- **Repair:** Ordered 8-parameter Compose ABI resolver and dynamic photo-viewer capability resolver.
- **Artifact:** `docs/newx-resolver-linter/artifacts/hide_post_reply_bar_recon.md`.

#### Open canonical URLs (`CanonicalUrlsPatch.kt`)
- **Cause:** 
  - `UrlEntity` class moved from `Lcom/x/models/text/m1;` to `l1;`.
  - The URL picker helper method `(String, String) -> String` was inlined into two dispatcher branches in `12.27`.
- **Repair:** Built dynamic shape adapter (`UrlPickerShape.Extracted` vs `UrlPickerShape.Inlined`) resolving both shapes without version branching. Derived field indices from wire serializer indices (0: `displayUrl`, 1: `expandedUrl`, 2: `url`).
- **Artifact:** `docs/newx-resolver-linter/artifacts/open_canonical_urls_recon.md`.

#### Restore timeline position (`RestoreTimelinePositionPatch.kt`)
- **Cause:** Target getter had one fewer original local register and R8 reused receiver register `p0`, starving `FreeRegisterProvider.getFreeRegister4Bit()` at `timelineResultIndex + 1`.
- **Repair:** Structurally reserved 5 scratch registers from the original register count before cloning (`[scratchBase, scratchBase + 4]`). Added fail-closed 4-bit range assertions and `move-object/from16` handling for shifted high parameter registers.
- **Artifact:** `docs/newx-resolver-linter/artifacts/restore_timeline_position_recon.md`.

#### Set default reply sorting (`DefaultReplySortingPatch.kt`)
- **Cause:** 
  - Compiler null-check lowering removed `"rankingMode"`.
  - Synthetic `Function0` UI state initializer moved from `Lcom/x/ui/common/` to `Lcom/x/urt/items/post/u0`.
- **Repair:** Removed `"rankingMode"` filter; dynamically resolved ranking enum (`ze` vs `af`); removed hardcoded package filter `Lcom/x/ui/common/` and resolved `Function0` by bytecode shape and Compose-runtime static call pairing.
- **Artifact:** `docs/newx-resolver-linter/artifacts/set_default_reply_sorting_recon.md`.

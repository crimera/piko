## Reproduction

`dexscope xref` for `Paint.setTypeface` callers under `androidx/compose`:

- 12.26.0-alpha.03 (`4a5bc95c…`): paragraph constructor is
  `Landroidx/compose/ui/text/platform/d;-><init>(Ljava/lang/String;Landroidx/compose/ui/text/c1;Ljava/util/List;Ljava/util/List;Landroidx/compose/ui/text/font/i;Landroidx/compose/ui/unit/c;)V`
  (6 params, setTypeface at index 223).
- 12.27.0-alpha.01 (`82d0fe72…`): that class is gone; the constructor is now
  `Landroidx/compose/ui/text/c;-><init>(Ljava/lang/String;Landroidx/compose/ui/text/e1;Ljava/util/List;Ljava/util/List;Landroidx/compose/ui/text/font/i;Landroidx/compose/ui/unit/c;Z)V`
  (7 params, trailing boolean added, setTypeface at index 224).

The old fingerprint scoped to `androidx/compose/ui/text/platform`, so it finds
zero methods on 12.27 and fails closed. Compose also renamed siblings
(`platform/f` TextPaint subclass is now `platform/e`, emoji2 `text/i` is now
`text/h`), consistent with a Compose version bump rather than R8 churn.

## Isolation comparison

No linter/helper change involved (`:patches:lintNewxResolvers` passes before and
after). Old scope reproduces zero matches on 12.27; the widened scope below
resolves exactly one constructor on both 12.26.0-alpha.03 and 12.27.0-alpha.01
via exhaustive `xref` caller enumeration (sibling callers `font/a->e` and
`style/b->updateDraw/MeasureState` are not constructors, so `name = "<init>"`
disambiguates).
